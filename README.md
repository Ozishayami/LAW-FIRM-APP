# Law Firm Management System

A desktop-first law firm operations platform, starting with a single firm and designed to support isolated firm workspaces in the future.

## Product direction

The application will bring client and matter management, tasks and checklists, calendar reminders, email communications, billing, receipts, documents, team permissions, and operational reporting into one workspace.

## Planned stack

- Next.js, React, and TypeScript
- Tailwind CSS
- Supabase (PostgreSQL, authentication, and private file storage)
- Gmail API / Google Workspace integration
- Vercel deployment

## Current status

Project foundation is being established. Integrations remain intentionally unconfigured until credentials and access policies are supplied. No production client or financial data should be entered until authentication, database policies, backups, and audit logging have been implemented and reviewed.
